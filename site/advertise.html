Advertise on PLAYPILE

Seven standard slots across the site, in the places people actually look, and nothing that interrupts a game in progress.

  • 728×90Home leaderboard, above the fold
  • 728×90Home in-feed, after the first row
  • 728×90Game page leaderboard
  • 300×250Game page rectangle, beside the game
  • 300×600Game page half page
  • 728×90Game page footer
  • 300×250Loading interstitial, skippable

The interstitial is shown while a game loads, never over one that is running, never more than once every three minutes per visitor, and it always has a skip. Everything else is a static unit in the page.

To turn the slots on: put your network's client id and slot ids in ads/ads.json and set enabled: true. Nothing else on the site needs changing. See MONETISATION.md in the project folder.
